# ScrewPAM

Phonon angular momentum and **pseudo-angular momentum (PAM) along screw axes**, computed from a
[phonopy](https://phonopy.github.io/phonopy/) calculation.

For crystals with an n-fold screw axis along c (e.g. P3₁21, P3₁12, P6₁, P6₅ …) every phonon on the line Γ–A is an
eigenstate of the screw operation g = {C<sub>n</sub><sup>+</sup>|τ}. ScrewPAM finds the screw from the crystal symmetry,
applies it to the phonopy eigenvectors and returns for every mode

* the frequency,
* the phonon angular momentum l<sub>z</sub> (Zhang & Niu 2014),
* the pseudo-angular momentum m (an integer, defined modulo n),
* |λ|, the modulus of the screw eigenvalue (1 for a clean eigenstate; use it to flag degenerate points).

## Definitions and conventions

* Phonopy eigenvectors: u<sub>κ</sub>(l, t) ∝ e<sub>κ</sub> exp(i **q**·**r**<sub>κl</sub> − iωt).
* Angular momentum (ħ):

  ```math
  l_z = \sum_\kappa \mathbf e_\kappa^\dagger M_z \mathbf e_\kappa ,\qquad (M_z)_{\alpha\beta} = -i\,\varepsilon_{z\alpha\beta}
  ```

  l<sub>z</sub> = +1 is counter-clockwise circular motion seen from +z.
* Screw eigenvalue: g u = λ u. Removing the phase of the translation, the PAM m is defined by

  ```math
  \lambda' = \lambda\, e^{\,i\,\mathbf q\cdot\boldsymbol\tau} = e^{-i\,2\pi m/n},\qquad -n/2 < m \le n/2 .
  ```

  This is the convention of Zhang & Murakami (2022) and Ishito et al. (2023) (the minus sign in the exponent).
  With it, a transverse acoustic mode with l<sub>z</sub> = +1 has m = +1 and the longitudinal acoustic mode has m = 0.
* At Γ and A degenerate modes may be any combination of the two partners: there |λ| < 1 is possible and m is not
  meaningful. On the open line Γ–A all non-degenerate modes are clean eigenstates.

## Installation

```bash
pip install .
```

Requires Python ≥ 3.9, numpy, phonopy ≥ 2.20 and spglib.

## Usage

Command line, with any phonopy file that contains forces or force constants:

```bash
screwpam phonopy_params.yaml --nq 201 --out pam.dat
```

`pam.dat` has the columns q<sub>z</sub> (2π/c), frequency (cm⁻¹), l<sub>z</sub> (ħ), m, |λ| for every mode.

Python:

```python
import numpy as np, phonopy, screwpam as sp

ph = phonopy.load("phonopy_params.yaml")
qz = sp.qpoints_gamma_a(201)                 # -A ... Gamma ... A
f, E = sp.modes_along_c(ph, qz)               # THz, eigenvectors (nq, modes, atoms, 3)
lz, lz_atom = sp.angular_momentum(E)          # hbar
m, mag, op = sp.pseudo_angular_momentum(ph, qz, E)
print(op["n"], op["tau"])                     # order of the screw and its translation
```

The opposite enantiomer can be generated exactly (structure and force constants) with
`sp.enantiomer(ph)`, so both hands have identical frequencies and differ only in handedness.

## Example and validation: tellurium

`examples/tellurium` reproduces the PAM assignment of Ishito *et al.* (2023) for trigonal Te:
*"in R-Te (P3₁21) the phonon of the split Γ₃ mode with a higher frequency has m = −1, whereas in L-Te (P3₂21) it has
m = +1."*

Input: R-Te with the lattice used by Ishito *et al.* (a = 4.512 Å, c = 5.960 Å, not relaxed) and the
phonopy `FORCE_SETS` from VASP (PBE, no spin-orbit coupling, PAW, 400 eV, 3×3×3 supercell, 4×4×4 k-mesh,
±0.01 Å). L-Te is generated by the exact mirror a₁ ↔ a₂.

```bash
cd examples/tellurium
python run_te.py
```

The script prints the Γ frequencies, l<sub>z</sub> and m at q<sub>z</sub> = 0.01 for both hands and checks the published
assignment for both Γ₃ doublets.

## Tests

```bash
pip install .[test]
pytest
```

The tests use the tellurium data and check: the screw operation found (3₁ for R, 3₂ for L); clean eigenstates on Γ–A;
acoustic modes (m = 0 for the longitudinal, m = sign(l<sub>z</sub>) for the transverse branches); time reversal
(m(−q) = −m(q), l<sub>z</sub>(−q) = −l<sub>z</sub>(q)); opposite m and l<sub>z</sub> in the two enantiomers; and the
assignment of Ishito *et al.* (2023).
